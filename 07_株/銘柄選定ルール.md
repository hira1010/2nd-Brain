# 投資戦略：配当貴族×逆張りガイド

本プロジェクトにおける、孫子の兵法に基づいた「負けない」ための具体的な銘柄選定ルールを定めます。

## 1. 原則：不敗の地に立つ

孫子は「不敗は己に在り」と説きました。投資における不敗の地とは、**「その企業が存続し、利益を出し続けることが極めて高い確率で保証されている状態」**です。

### なぜ「配当貴族」なのか（品質の担保）

- **連続増配の証明**: 25年以上にわたり増配を続ける企業は、リーマンショックやコロナショックなどの幾多の荒波を乗り越えてきた「真の勝者」です。
- **強固なビジネスモデル**: 利益を出し続け、さらに株主に還元し続けることができる圧倒的な参入障壁やブランド力を持っています。
- **倒産リスクの極小化**: 財務基盤が健全でなければ、四半世紀もの連続増配は不可能です。

## 2. 戦術：逆張りによる安全域の確保

「可勝は敵に在り」——勝てる（利益が出る）かどうかは市場が決めることですが、安く買う（負けない準備をする）ことは自分の意志で決めることができます。

### なぜ「逆張り」なのか（安全域）

- **バリュエーションの歪み**: 暴落時や一時的な悪材料での売り浴びせは、優良企業の株価を「本来の価値（PERや配当利回りベース）」以下に押し下げます。
- **利回りの最大化**: 株価が下がった状態で買うことで、初期投資額に対する配当利回りを最大化し、将来の増配による恩恵をより強く受けられます。
- **心理的優位性**: 多くの投資家がパニックで投げ売りしている時に買うことで、後に市場が冷静さを取り戻した際、圧倒的な含み益という「守り」を持つことができます。

## 3. 具体的な運用ルール（型）

1. **スクリーニング**: 25年以上連続増配の「配当貴族」リスト（S&P 500 Dividend Aristocrats等）を監視対象とする。
2. **待機**: ターゲット銘柄が、全体の市場暴落や個別の一時的な不調で大きく売られるまで「じっと待つ」。
3. **実行**: 自分の設定した「安全域（例：配当利回りヒストリカルの高水準）」に達した際、分割して買い向かう。
4. **継続**: 買った後は「配当貴族」のキャッシュフローを信じ、長期保有で「経験の複利」と「試行回数」を稼ぐ。

## 結論

「配当貴族」という最強の盾を、「逆張り」という最も有利なタイミングで構える。これこそが、本プロジェクトが目指す**「不敗の挑戦者」**の具体的な姿です。
