## ゲーム概要

- **ゲーム名**: モグラたたき (Whack-A-Mole)
- **1行説明**: 9つの穴から出てくるモグラを60秒間で何匹叩けるかを競うミニゲーム
- **ジャンル**: ミニゲーム / カジュアル
- **想定プレイ時間**: 1プレイ約60秒
- **想定プラットフォーム**: スマホ縦持ち（941x1672 縦長UI想定）/ PC横持ちでも可

---

## 画面構成

**Title → InGame → Result → Title** の 3画面循環。同一シーン内のパネル切替で実装する。

- **Title**: 背景画像 + START ボタンのみ。タイトル文字は背景画像 `title_background.png` にすでに含まれているので **TMP テキストで重ねない**
- **InGame**: 背景 + 9個のモグラ穴 + スコア表示 + 残り時間表示
- **Result**: 最終スコア + 「もう一度」「タイトルへ」の2ボタン

---

## ゲームルール

- **勝敗・終了条件**: 制限時間 60秒経過で終了。スコアのみ記録
- **スコア計算**: モグラを叩くと **+10**、見逃し（モグラが自然に引っ込むのを許す）で **-3**
  - ただし **スコアの最低値は 0**（マイナスにはならない、0 で頭打ち）
- **タイマー**: 60秒カウントダウン、0秒で Result へ自動遷移
- **同時出現**: 最大3匹（穴だけの時間がほぼ無いように高頻度スポーン）

## 特殊な見た目・構造の注意

### モグラ穴は2層構造

通常の View は1層だが、モグラ穴は **2層**:
- **下層**: 「空の穴」の絵（`mole_idle.png`）が常に見えている（消えない）
- **上層**: モグラ本体。出現中だけ見える、引っ込んだら見えなくなる

下層と上層は同じ穴 View 内で管理する。

### 9穴の配置範囲（重要）

9個の穴 (3x3) は **`stage_background.png` の土エリア（茶色部分）の内側**に収まるように配置する。

- 緑の草地部分にはみ出さないこと
- 背景画像のサイズではなく、背景画像内の **視覚的な土エリアの境界**を見て配置範囲を決める
- 配置後は Game ビューで「9個全部の穴が土エリア内に乗っているか」を目視確認する

### 2層構造の中心合わせ（重要）

上層モグラは下層穴 (`mole_idle.png`) の **視覚的中心**に重ねる。

- Sprite Pivot や RectTransform anchoredPosition を、穴画像の **見た目の中心**（土が盛り上がった円の中心）に合わせる
- 画像ファイルの矩形中心と視覚的中心がずれている場合は、視覚的中心を優先する
- 配置後は Game ビューで「モグラが穴の真ん中に乗っているか」を目視確認する

## ゲーム要素の挙動

### モグラ穴

- タップで叩ける（ヒット判定が無効のときは反応しない）
- **出現アニメ**: 勢いをつけて飛び出す感じ（少し行き過ぎてから戻るような動き）。スプライトは "出現" 用 (`mole_appear.png`) に切り替える
- **叩かれアニメ**: 鋭く速く縮みながら消える。スプライトは "叩かれ" 用 (`mole_hit.png`) に切り替える
- **見逃しアニメ**: 徐々に加速しながら穴に潜って消える。スプライトは "退散" 用 (`mole_escape.png`) に切り替える
- 「空の穴」(`mole_idle.png`) は **アニメ完了後も idle に戻さない**（下層で常時表示しているので、上層は単に非表示にするだけ）
- ヒット判定の有効/無効を外から切り替えられる
- 演出を出すための位置（世界座標）を外から取得できる

### モグラスポーン制御

- ランダムに穴を選んでモグラを出現させる
- 同時最大 3匹まで
- スポーン間隔はランダム（`spawnIntervalMin` 〜 `spawnIntervalMax` の範囲）
- 9個の穴は **論理インデックス（0〜8）** で識別される
- Logic 側は インデックスで管理（穴 View そのものは知らない）
- Presenter が「インデックス → 実際のモグラ穴 View」のマッピングを担当する
- ヒット時・見逃し時に Logic から通知が出る（インデックス付き）
- Presenter が通知を受けて、スコア機能やヒット演出に伝える

### スコア

- ヒット時に +10、見逃し時に -3 加減算
- スコアが変わったら通知を発火（後で View に反映するため）
- スコアの上限なし（マイナスも許容）

### タイマー

- 制限時間 60秒のカウントダウン
- カウントダウン中は残り秒数を毎フレーム通知
- 0秒で「時間切れ」を通知（後で画面遷移に使う）
- リセットで初期値に戻せる

### 画面遷移

- Title → InGame → Result → Title の循環
- Title の START ボタンで InGame へ
- InGame でタイマーが時間切れで Result へ
- Result の「もう一度」で InGame に戻る（スコア・タイマー・スポーンを正しくリセット）
- Result の「タイトルへ」で Title に戻る

## 演出のイメージ

### ヒット演出

モグラを叩いたときの演出。3要素を **同時に**発火する:

#### 星のキラキラ
- 5枚の星のスプライト（`hit_particle_star_00〜04`）をパラパラ漫画みたいに切り替えて見せる
- ヒットした位置から放射状に **8〜10個ぐらいまとめて飛び散る**
- 円形の範囲から放出する感じ

#### 斬撃
- 4枚の斬撃スプライト（`hit_particle_slash_00〜03`）をパラパラ漫画で見せる
- **1個だけ**ランダムな角度で大きく出す（範囲指定なし、その場で）

#### 中心のドカン
- `hit_particle_base.png` を中心にポンと出して、拡大しながらフェードアウトさせる

ヒット位置（モグラの世界座標）を渡すとその場所で発火する。1回再生したら自動で消える。
（技術補足: ParticleSystem の lifetime で自動消滅、CancellationToken 不要）

### 演出のサイズ感（重要）

ヒット演出の **全体サイズはモグラ穴1個分程度**に収める。

- 画面いっぱいに広がるような派手すぎる演出は避ける
- star のスケール・slash のサイズ・base の DOScale 倍率は「**モグラ穴と同じくらい**」を基準に調整
- 周辺の穴を覆い隠すほど大きくしない
- 「叩いた場所で何かが弾けた」が伝わる程度のメリハリ感で十分

### スコア演出（任意・仕上げで追加）
- スコア更新時に数字が **0.2秒ぐらいでカウントアップ**するアニメ
- 増点時のみ、文字を一瞬大きく弾ませる + 黄色く光らせて元の色に戻す

### START ボタン演出（任意・仕上げで追加）
- タイトル画面の START ボタンを 1秒周期で点滅させる（フェードイン・フェードアウトの繰り返し、片道0.5秒）
- ボタンの **背景画像とラベル(TMP)が同期して**フェードする（CanvasGroup を使う）

## ゲーム固有の完成判定

Core_共通テンプレ.md の共通完成判定に加えて、以下を満たすこと:

- [ ] **タイトル画面に追加の TMP テキストが乗っていない**（背景のロゴのみ）。中央付近に START ボタンだけ
- [ ] モグラを叩くとスコアが **+10**、見逃すと **-3** が反映される
- [ ] **スコアが 0 を下回らない**（マイナスにならない、0 で頭打ち）
- [ ] **9個の穴が `stage_background.png` の土エリア内に収まっている**（緑草地にはみ出していない）
- [ ] **モグラが穴の視覚的中心に乗っている**（モグラと穴がずれていない）
- [ ] **ヒット演出のサイズが常識的範囲**（モグラ穴1個分程度、画面いっぱいに広がっていない）
- [ ] **インゲーム中、9個の穴がずっと見えており**、その上にモグラが出たり消えたりする（= 2層構造が正しく動いている）
- [ ] **モグラが画面に出ている時間が体感的に長く**、穴だけの時間がほぼない（タップが間に合う遊び心地）
- [ ] 制限時間 60秒のカウントダウンが動く
- [ ] ヒット演出に **星系・斬撃系の両方の素材**が ParticleSystem で使われている
- [ ] EditMode テストが Logic 各クラス分（GameConfig / ScoreLogic / TimerLogic / MoleSpawnerLogic）について全件 Pass
