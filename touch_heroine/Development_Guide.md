# 教室クリッカー：制作ガイド (RPGツクールMZ用)

このガイドは、セットアップした仕組みを使って、実際にゲームを組み立てる手順を解説します。

## 1. 準備：エディタを開く

フォルダ内の `Game.rmmzproject` をダブルクリックして、RPGツクールMZでプロジェクトを開いてください。

## 2. 変数とスイッチの確認

「データベース」の「用語」や「イベントの編集」画面で、以下の名前が登録されていることを確認してください。

## 標準データ定義（リファクタリング後）

このプロジェクトでは、管理を容易にするために以下のプレフィックスを使用しています。
- `[CLI]`: クリッカーパート関連
- `[SEA]`: 探索・謎解き関連
- `[SYS]`: システム・デバッグ関連

### 重要変数一覧

| ID | 名前 | 説明 |
|:---|:---|:---|
| 9 | [CLI] 現在の快感 | 蓄積された快感値（90%以上でフィニッシュ可） |
| 10 | [CLI] 目標快感 | ステージクリアに必要な快感値 |
| 11 | [CLI] 残り時間(秒) | クリッカーパートの制限時間 |
| 15 | [CLI] 判定部位ID | 1:耳, 2:胸, 3:股間（スクリプトで使用） |
| 16 | [CLI] 羞恥心 | 快感の上昇に影響する精神ステータス |
| 17 | [CLI] 快楽許容 | 倍率計算に使用されるステータス |
| 19 | [CLI] 警戒度 | 100に達するとステルス失敗 |
| 20 | [CLI] 演出トリガー | 1:小揺れ, 2:大揺れ（コモン27で使用） |
| 21 | [CLI] クリック数 | 統計・アチーブメント用 |
| 22 | [CLI] 現在のランク | 親密度や進行度に応じたランク(1-3) |
| 23 | [CLI] 獲得報酬 | セッション中に獲得したポイント |
| 12 | [SEA] 発見アイテム数 | 現在のマップで見つけた数 |
| 13 | [SEA] 目標アイテム数 | マップクリアに必要な合計数 |
| 14 | [SEA] 選択中アイテムID | アイテム選択UIで選ばれたID |

### 重要スイッチ一覧

| ID | 名前 | 説明 |
|:---|:---|:---|
| 9 | [CLI] 実行中フラグ | ONの間、クリッカーUIと判定が有効化 |
| 10 | [CLI] 足音警戒中 | ONの間、クリックで警戒度が上昇 |
| 11 | [SEA] 探索モード | ONの間、探索HUDと接近ヒントが表示 |
| 12 | [SYS] ステルス隠れ | プレイヤーが隠れているかどうかの判定 |

- **変数**:
  - 9番: `[クリッカー] 現在の快感`（現在のスコア）
  - 10番: `[クリッカー] 目標快感`（クリアに必要な数値）
  - 11番: `[クリッカー] 残り時間(秒)`（カウントダウン）
- **スイッチ**:
  - 9番: `[クリッカー] 実行中フラグ`（これをONにするとゲーム開始！）

## 3. ゲームを「開始」させる方法

マップ上のイベント（机や扉、あるいは自動実行イベント）に、以下の3つを設定してください。

1. **変数の操作**: `[クリッカー] 残り時間(秒)` を `3600`（1時間分）に設定。
2. **変数の操作**: `[クリッカー] 目標快感` を `10000`（お好みで）に設定。
3. **スイッチの操作**: `[クリッカー] 実行中フラグ` を `ON` にする。

これだけで、1秒ごとに自動で時間が減り、自動ポイント（秒間獲得量）があれば快感が増えていきます。

## 4. 「クリック」で快感を増やす方法

彼女の立ち絵を表示し、クリックに反応させる手順です。

1. **ピクチャの表示**: 彼女の画像を画面に表示します。
2. **ボタン化**: 公式プラグイン `ButtonPicture.js` をプラグイン管理で有効にします。
3. **設定**: 「ピクチャのクリック時にコモンイベントを呼び出す」設定で、新しいコモンイベント（クリック時に変数を増やす処理）を作って指定します。

## 5. 探索パートとのつなぎ

1. 探索用マップでアイテムを手に入れたら、`[クリッカー] 秒間獲得量` や `[クリッカー] クリックパワー` の変数をプラスしてください。
2. 準備ができたら、上記の「ゲーム開始」処理を呼び出すだけです。
