# 21_プロレスゲーム 🎮🔥

Pyxel（2D）とThree.js（3D）で展開される、究極の2D/3Dハイブリッド・プロレスゲーム開発プロジェクトです

## 🕹️ 使い方（操作方法）

### 1. 2D版 (Pyxel版: `main.py`)

レトロなドット絵で爽快な打撃を楽しめます

- **移動**: カーソルキー（上下左右）
- **ダッシュ**: 左右キーを2回連続で押す（ダブルタップ）
- **打撃 (Strike)**: `Z` キー（ダッシュ攻撃も可能）
- **投げ (Grapple)**: `X` キー（相手と重なっている時に有効）
- **必殺技 (Special)**: `Space` キー（ゲージ満タン時にバックドロップ発動）
- **リスタート**: `R` キー（試合終了後）

### 2. 3D版 (Web版: `dist/index.html`)

スマホやPCブラウザで、臨場感ある3Dプロレスを体験できます

- **移動**: 左下のバーチャルジョイスティック（マウスまたはタッチ）
- **各種アクション**: 右側のボタン群を操作
  - **STRIKE**: 打撃攻撃
  - **DASH**: 押している間ダッシュ移動
  - **THROW**: 投げ技（相手の近くで有効）
  - **SPECIAL**: 必殺技演出の発動（ゲージ満タン時）
  - **FALL**: 相手がダウン中にクリックしてフォール開始
- **カメラ**: キャラクターの背後を自動追従（オートカメラ）

## 🏆 ゲームのルール

- **体力（HP）**: 相手のHPを削り、ダウンを奪うことが基本です
- **必殺技ゲージ**: 攻撃を当てるとゲージが溜まり、100%で超強力な「スペシャルムーヴ」が放てます
- **フォール**: 相手がダウンしたら重なってフォール（FALL）開始　3カウント入れば勝利です
  - **レフェリーカウント**: カウント2で返される（キックアウト）こともあります
- **AI挙動**: コンピュータは軸を合わせたり、適切な距離を取ってきたりする戦略的な動きを見せます

## 📁 構成

- `main.py`: Pyxelによるコアゲームエンジン（2D版）
- `index.html`: WebAssembly/JS/Three.js版のエントリーポイント
- `game.js`: 3Dレンダリングと物理演算ロジック
- `assets/`: キャラクターやエフェクト専用イメージバンク
