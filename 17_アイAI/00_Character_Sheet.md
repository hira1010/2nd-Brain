# キャラクター設定：アイ (Ai Character Sheet)

アイ（Ai）のビジュアルを「最新のAI生成画像と同等の高精細キャラ」として固定するためのマスターアンカーです。

## 📌 高精細モダン・ビジュアル (High-Fidelity Modern Visuals)

| 項目 | 高密度・高精度な設定内容 |
| :--- | :--- |
| **線画** | **極めて繊細で鋭い「生きた」極細線**. 強弱があり、キャラクターを柔らかく包む。 |
| **瞳** | **宝石のように多層的で複雑な琥珀色**. 繊細なまつ毛、潤みのある瞳、複雑な反射。 |
| **髪** | 非常に短い黒髪。**一本一本の毛束が判別できるほど繊細な書き込み**と、透明感のあるハイライト。 |
| **塗り** | 滑らかなグラデーションを伴う、洗練された多層セル塗り。 |
