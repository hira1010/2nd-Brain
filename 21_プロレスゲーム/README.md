# 21_プロレスゲーム

Pyxelを使用したプロレスゲームの開発プロジェクトです。

## 概要

- **エンジン**: Pyxel (Python)
- **ジャンル**: プロレス・アクション
- **目標**: 爽快感のある打撃、投げ技、関節技を組み合わせた2Dプロレスゲームの構築。

## 初期構成

- `main.py`: エントリーポイント兼基本ゲームループ
- `assets/`: 画像、音声素材（予定）
