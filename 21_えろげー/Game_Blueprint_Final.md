# RPGツクールMZ 実装設計図：ヒロイン密着クリック＆チェキ経済ADV（最新版）

このドキュメントは、要件定義に基づく「クリック」「チェキ撮影」「経済サイクル」をRPGツクールMZで実現するための具体的な構築図です。**「足音（ステルス）」要素は完全に排除**し、彼女との密着と経済に特化した設計となっています。

---

## 1. 変数・スイッチの割り当て（システム構成図）

システムの心臓部となる数値の管理場所を定義します。

### 【変数リスト (Variables)】
| ID | 名前 | 説明 |
| :--- | :--- | :--- |
| **0009** | **親密度** | クリックで上昇。ランクアップのトリガーになるメイン数値。 |
| **0010** | **親密度ランク** | 1=知り合い, 2=意識している, 3=特別な関係（立ち絵・台詞に対応）。 |
| **0011** | **一時報酬額** | チェキ売却時に計算される金額。その後所持金に加算する。 |
| **0012** | **機謙値** | クリックの度に少しずつ低下。0になると「お仕置き中」へ。 |
| **0013** | **クリック上昇量** | (基本値 × 装備倍率) で計算される。 |
| **0015** | **判定部位** | 1=頭, 2=胸, 3=下半身。クリックした場所を記録。 |

### 【スイッチリスト (Switches)】
| ID | 名前 | 説明 |
| :--- | :--- | :--- |
| **0001** | **ゲーム進行中** | このスイッチがONの間だけ並列イベントが動くようにする。 |
| **0002** | **お仕置き中** | ONの間はクリック操作を受け付けない唯一の制限状態。 |

## 2. コモンイベント設計（ロジックの極意）

全ての処理は「コモンイベント」にまとめ、呼び出すだけにします。

### ① 【クリック処理】 (Common Event ID: 22)
**トリガー：なし（マップ上の透明イベントから呼び出し）**
1.  **条件分岐**：スイッチ [お仕置き中] が ON なら → **イベント中断**
2.  **スクリプト**：`$gameVariables.setValue(15, TouchInput.y < 200 ? 1 : TouchInput.y < 350 ? 2 : 3);`
3.  **変数の操作**：[親密度] += [クリック上昇量]
4.  **変数の操作**：[機謙値] -= 5
5.  **演出呼び出し**：[ポップアップ演出]、[ボイス演奏]
6.  **条件分岐**：[機謙値] <= 0 なら → **スイッチ [お仕置き中] を ON にする**

### ② 【チェキ撮影＆自動販売】 (Common Event ID: 30)
**トリガー：なし（ボタンクリックから呼び出し）**
1.  **SEの演奏**：シャッター音 (Camera)
2.  **フラッシュの演出**：画面のフラッシュ (白, 10フレーム)
3.  **条件分岐**：変数 [親密度ランク] 
    - **ランク 1なら**：[一時報酬額] = 500, メッセージ「清楚な日常チェキを¥500で売却した。」
    - **ランク 2なら**：[一時報酬額] = 2000, メッセージ「密着した親密チェキを¥2,000で売却した。」
    - **ランク 3なら**：[一時報酬額] = 5000, メッセージ「最高に背徳的なチェキを¥5,000で売却した！」
4.  **金額の加算**：`$gameParty.gainGold($gameVariables.value(11))`

### ③ 【お仕置きタイム（並列処理）】 (Common Event ID: 40)
**トリガー：並列処理（スイッチ [お仕置き中] が ON）**
1.  **文章の表示**：(彼女の怒った顔とボイス)「……もう、しつこいよ」
2.  **ウェイト**：600フレーム (10秒間、一切のクリックを拒否するじらし時間)
3.  **変数の操作**：[機謙値] = 100 (全回復)
4.  **スイッチの操作**：[お仕置き中] = OFF
5.  **文章の表示**：(彼女の表情が戻る)「……次は、優しくしてね？」

## 3. 経済・装備システムの極意

稼いだお金で「クリック力」を強化するのが攻略の近道です。

### 【装備アイテム】
- **リボン/香水/フェロモン剤** など。
- 持っているだけで計算式（[クリック上昇量]）がブーストされるように設計します。
- スクリプトなしでも、コモンイベントの冒頭に「条件分岐：リボンを持っているなら倍率を変数に代入」と入れるだけで実装可能です。
