# リバースエンジニアリング結果報告：ティルティと不思議なダンジョン_体験版

本プロジェクトの構造および主要なシステムの解析結果を報告します。

## 1. プロジェクト基本情報
- **ゲームエンジン**: RPGツクールMZ (v1.4.4以降と推測)
- **プラットフォーム**: NW.js (Windows用実行ファイル)
- **データ形式**: 全てのデータベース・マップは `data/` フォルダ内の `.json` 形式。

## 2. アセットの保護（暗号化）
画像および音声アセットはRPGツクール標準の機能で暗号化されています。
- **暗号化キー**: `3b234795bbf93260e23d7589b8373d5b`
- **対象ファイル拡張子**:
    - 画像: `.png_` (復号後は `.png`)
    - 音声: `.ogg_` (復号後は `.ogg`) / `.m4a_` (復号後は `.m4a`)

## 3. 独自ゲームシステム (RogueLike.js)
通常のRPGツクールの戦闘を使用せず、マップ上で完結する**ターン制ローグライクバトル**が実装されています。
- **ターン管理**: プレイヤーが1アクション（移動・攻撃・アイテム）行うごとに、`Fturn` と `Eturn` 変数を用いて敵の行動を同期させています。
- **攻撃システム**: 
    - 決定ボタンで正面の敵に攻撃。
    - 装備中の「防具（衣装）」に応じて、攻撃射程 (`range`) や特殊アクションが変化。
    - 射程の定義例: 通常(0), 槍(1: 3マス), ドリームソード(2: 広範囲), 周囲8マス(3)。
- **ダメージ計算**: プラグイン内で独自の計算式 (`atk * mag - def`) が定義されています。

## 4. ダンジョン生成システム (RandomDungeon.js)
「ピース」と呼ばれる小規模なマップパーツを動的に繋ぎ合わせる方式を採用しています。
- **生成ロジック**: 
    - `Base` マップを起点に、上下左右の通路配置が一致する `Piece` マップをランダムに接続。
    - 通路がない部分は `Void` マップで埋める。
- **イベント配置**: `unique` タグを用いて、ダンジョン内の特定の場所に「階段」や「宝箱」を確実に、かつ重複なく配置する仕組みがあります。

## 5. 主要なデータ変数
- **変数15**: 衣装の耐久値（ダメージを受けると上昇、一定値で衣装破壊イベント発生）。
- **変数21**: 巨乳化回数などの状態管理。
- **スイッチ3**: 死亡判定。

## 総評
本ゲームはRPGツクールの枠組みを使いつつも、主要なゲームシステム（移動、戦闘、マップ生成）をJavaScriptプラグインで完全に独自実装しており、技術的に高度な構成となっています。
