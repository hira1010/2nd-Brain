# 05_RPG制作 プロジェクト

## 概要
このプロジェクトは、RPGツクールMZを使用したアクションバトルシステム（ABS）の実装実験プロジェクトです。
フィールド上で「オノマトペ（バーン！等）」を投げて敵を攻撃することができます。

## 操作方法
- **Qキー / Wキー**: 前方にオノマトペを投げます。
- **命中**: 敵（イベントのメモ欄に `<Enemy>` と記載があるもの）に当たるとアニメーションと共にダメージボイスが再生されます。

### 1. オノマトペ7種・個性化システム (7-Type Expansion)
オノマトペを計7種類に拡大し、それぞれに独自の性能とビジュアルを与えました。
- **① バーン**: 【標準】バランスの取れた性能。
- **② ドドド**: 【重撃】射程は短いが、圧倒的な威力と爆発演出。
- **③ ドキドキ**: 【射抜き】超高速・長射程で遠くの敵を貫く。
- **④ ふわっ**: 【浮遊】ゆっくりと飛び、広範囲をカバー。
- **⑤ ちゅちゅ**: 【至近】目の前を素早く攻撃。
- **⑥ きゅん**: 【衝撃】強い閃光と共に敵を撃破。
- **⑦ わくわく**: 【拡散】不思議な光の弾を放つ。

### 2. サイズ調整 (Size Fix)
- **修正**: 「オノマトペがでかすぎる」というフィードバックに基づき、表示スケールを**10%（開始）〜40%（最大）**にさらに抑制。
- **効果**: 画面を遮ることなく、非常にコンパクトでスタイリッシュな投擲アクションが可能になりました。

### 3. 獲得・切り替えシステム (Inventory & Cycle)
- **獲得**: マップ上に配置された「宝箱」からそれぞれの極意をゲットすることで、新しいオノマトペが解禁されます。
- **切り替え**: **Shiftキー**で、今持っているオノマトペをリアルタイムに切り替え可能。切替時には装備名と説明が表示されます。

### 4. 当たり判定の広域化 (Collision Update)
- **修正**: これまではプレイヤーの目の前1マスしか判定がありませんでしたが、オノマトペを投げた際の「飛んでいく全軌道（射程分）」に判定を広げました。
- **効果**: 「ドドド（短射程）」から「ドキドキ（長射程）」まで、全てのオノマトペで遠くの敵を正確に倒せるようになりました。

### 5. 音声ロードエラーの修正 (Audio Fix)
- **修正**: 一部のボイスSEで発生していた「Failed to load」エラーを修正しました。ファイル名をインポート済みの正規の名称（AnyConv.com...）と完全に一致させ、ランダム再生も安定して動作するようにしました。

## 実装の詳細
- **ABS_Support.js**: 投擲座標計算、当たり判定、演出制御を司る専用プラグインです。
- **コモンイベント2**: ABSの実行エントリです。
- **コモンイベント3**: キー入力の監視（並列処理）です。

## フォルダ構成
- `audio/se/`: インポートした大量のダメージボイスが格納されています。
- `img/pictures/`: インポートしたオノマトペ画像が格納されています。
- `tools/`: 開発支援用のスクリプトが格納されています。
- `archive/`: 旧バージョンのプロジェクトデータが保管されています。
