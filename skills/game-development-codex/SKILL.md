# ゲーム開発（Codex流）スキルガイド

このスキルは、OpenAI Codexのドキュメントに基づいたゲーム開発プロンプトの手法をまとめたものです。

## 1. 開発フロー
ゲーム開発を以下の6つのステップに分けて進めます。

### 1-1. コンセプト記述 (Concept Description)
まず、ゲームの動作内容を明確に記述します。
- プレイヤーは何をするのか？
- 勝利条件と敗北条件は？
- 操作方法は？

### 1-2. レンダリングレイヤーの作成 (Rendering Layer)
ロジックを書く前に、描画の仕組みを構築します。
- HTML5 Canvasや、PixiJS/Three.jsなどのライブラリの初期化。
- 背景、キャラクター、アイテムを表示するための基本関数を作成。

### 1-3. フロントエンドシェル (Front-end Shell)
UIやボタン、スコア表示などの外枠を作成します。
- 画面レイアウトの構築。
- スタートボタンやリセットボタンの配置。

### 1-4. 状態管理 (State Management)
ゲームの「今」の状態を管理する仕組みを作ります。
- プレイヤーの位置、スコア、残り時間などの変数の定義。
- `update()` 関数の実装。

### 1-5. アセット制作 (Asset Production)
ビジュアル要素を追加します。
- 画像（スプライト）やサウンドの読み込み。
- プレースホルダーから実際の画像への差し替え。

### 1-6. 継続的な調整 (Visual Adjustment)
動かしながら微調整を行います。
- アニメーションのスピード。
- ヒット判定の正確さ。
- 色彩やエフェクトの追加。

## 2. プロンプトのコツ
- **段階的に依頼する**: 一度に全てを作らせるのではなく、まず「Canvasの準備だけ」のように細かく分けます。
- **視覚的なフィードバックを活用する**: 画面を見て「右にずれている」などの修正を繰り返します。
- **状態を明確にする**: 「今のスコアをグローバル変数で管理して」と指示します。
