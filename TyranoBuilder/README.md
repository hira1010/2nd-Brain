# 🎮 ティラノビルダー版 クリッカーゲーム制作キット

このフォルダには、ティラノビルダー（TyranoBuilder）でクリッカーゲームを構築するための **シナリオとロジック（仕組み）** が含まれています。

## 📥 導入方法 (How to Use)

ティラノビルダーのソフトウェア本体（エンジン部分）はファイルサイズが大きいため、以下の手順でこのスクリプトを組み込んでください。

1. **ティラノビルダー** を起動し、新しいプロジェクトを適当な名前で作ります。
2. 作成したプロジェクトのフォルダを開きます。
3. **`data/scenario/`** フォルダにある `scene1.ks` を、本フォルダ内の同名ファイルで上書き（または中身をコピー）してください。
4. **`data/bgimage/`** と **`data/fgimage/`** に、本フォルダ内の画像ファイルをコピーしてください。
5. ティラノビルダーに戻り、「プレビュー」を実行すると動作が確認できます。

## 🛠️ このキットに含まれる機能

- **継続クリック判定**: ヒロインの胸などをクリックすると親密度がたまります。
- **ランクアップシステム**: 親密度が一定（40以上、100以上）たまると自動でランクが上がります。
- **経済サイクル**: 「チェキを撮る（売却）」ボタンで、現在の親密度をお金（円）に換算します。
- **お仕置きモード**: 連続でクリックしすぎると、一定時間操作不能になるお仕置きが発動します。
- **ステータス表示**: 画面左上に、リアルタイムで数値が表示されます。

## 🔧 カスタマイズのヒント

- **`data/scenario/scene1.ks`** の中にある `f.intimacy += 2;` などの数字を変えることで、難易度（貯まりやすさ）を調整できます。
- `[clickable]` タグの座標（x, y）を調整することで、クリックできる場所を変更できます。
