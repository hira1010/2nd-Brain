# 🧬 22_遺伝子解析 (Genetic Analysis)

このフォルダは、遺伝子解析サービス（Dr. Gene等）の結果を蓄積・分析し、個人の健康管理やダイエット戦略に最適化するための場所です。

## 🎯 目的

- 自分の遺伝的体質（代謝、肥満タイプ、筋肉特性等）を正確に把握する。
- 科学的根拠に基づいた「自分専用のダイエット・運動計画」を策定する。

## 📂 構成

- `README.md`: このファイル。フォルダの概要。
- `遺伝子解析結果_要約.md`: (作成予定) 各解析結果のサマリー。
- `archived_data/`: (将来用) 解析元データやPDFの保管場所。

## 🛡️ 取り扱いルール

- このフォルダ内の情報は極めてプライベートな情報を含むため、外部への流出に注意する。
- 解析結果に基づいたアドバイスは、`01_ダイエット/記録.md` や `2026年03月_ダイエット計画.md` に適宜反映させる。
