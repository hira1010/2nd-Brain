# AI Agents Guidelines | Antigravity Engine

本プロジェクトにおいて、AIエージェント（あなた）が作業を行う際の最優先ガイドラインです。常に以下の手順に従い、品質と整合性を維持してください。

## 🛡️ 品質保証ルール (Quality Assurance)

1. **修正後の自己検証義務**
   `game/logic.rpy` などのロジック層、または `game/screens.rpy` などの表示層に修正・変更を加えた後は、必ず以下のテストスクリプトを実行してください。
   ```powershell
   python scripts/antigravity_check.py
   ```

2. **完了報告（DONE）の条件**
   - 上記テストを実行し、すべての項目が **GREEN (PASS)** であることを確認すること。
   - 変更によって既存の既存のテストが壊れた場合は、その理由をユーザーに説明し、合意の上でテストコード側を更新すること。
   - 1つでも **RED (FAIL)** がある状態での完了報告は、規約違反とみなします。

3. **報告時の記載**
   ユーザーへの報告の冒頭に `[Self-Check: ✅]` と記載することで、テストを通過したことを証明してください。

## 🛠️ 開発時の注意点

- **アセットパスの保護**: 画像や音声のパスを変更する、またはファイルを削除する際は、必ず `antigravity_check.py` の整合性チェックも更新し、ファイルが存在することを確認してください。
- **計算式の整合性**: 親密度倍率やチェキの価格計算式を変更した場合は、テストコード内のアサーション（期待値）も整合するように修正してください。
