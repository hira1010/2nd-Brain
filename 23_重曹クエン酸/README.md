# 23_重曹クエン酸 🥛✨

このフォルダは、重曹とクエン酸を活用した健康管理や日常生活の知恵を蓄積する場所です

## 1. 重曹クエン酸水の健康効果

重曹（炭酸水素ナトリウム）とクエン酸を水に溶かすことで、炭酸ガスが発生し、以下のような効果が期待できます

- **疲労回復**: クエン酸がエネルギー代謝（TCA回路）をサポートします
- **pHバランスの調整**: 体内の酸性・アルカリ性のバランスを整えます
- **消化促進・胃の不快感緩和**: 重曹の弱アルカリ性が胃酸を中和し、炭酸ガスが胃を刺激します
- **便秘解消**: 炭酸ガスが腸の活動を促します
- **代謝向上**: 血行を促進し、基礎代謝を上げる可能性があります

## 2. 基本的な飲み方

作りすぎや飲みすぎに注意し、以下の目安を守ってください

### 材料（1杯分）

- 水: 200ml
- 重曹（食用）: 小さじ1/4（約1g）
- クエン酸（食用）: 小さじ1/4（約1g）

### 手順

1. 水に重曹を入れてよく溶かします
2. そこにクエン酸を加え、発泡させます
3. 飲みづらい場合は、はちみつやレモン汁を少々加えると美味しくなります

### 飲むタイミング

- **食後や軽食後**がおすすめです（空腹時は胃への刺激が強いため避けてください）
- 1日**3杯（600ml）まで**を目安にしてください

## 3. 注意事項 ⚠️

- **食用を使用すること**: 掃除用は不純物が含まれているため、必ず「食品添加物」グレードのものを選んでください
- **塩分の過剰摂取**: 重曹にはナトリウムが含まれるため、高血圧や腎臓に持病がある方は医師に相談してください
- **歯のエナメル質**: 酸性のクエン酸は歯を溶かす可能性があるため、飲んだ後は口をゆすぐか、ストローの使用を推奨します

## 4. その他の活用法

- **掃除**: 重曹は油汚れに、クエン酸は水垢汚れに効果的です
- **入浴剤**: 重曹とクエン酸をお風呂に入れると、自家製の炭酸泉になり血行を促進します

---
> [!IMPORTANT]
> 健康効果については個人差があります　体調に異変を感じた場合はすぐに中止し、専門家に相談してください
