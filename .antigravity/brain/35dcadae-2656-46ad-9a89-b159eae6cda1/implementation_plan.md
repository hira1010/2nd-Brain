# 4ページ構成マンガスクリプト作成計画：「過去と他人の断絶」

アドラー心理学の「過去と他人は変えられない」という原則を投資と成功の文脈で解説する4ページ（EP13.21）を作成します。

## 概要

- **エピソード番号**: EP13.21
- **テーマ**: 過去や他人に費やすエネルギーを、自己と未来への投資（4P）に転換する。
- **ページ構成**: 4ページ

## 構成案

### ページ1：変えられないものへの執着

- **内容**: 優斗が過去の失敗や他人の評価に悩んでいる様子。
- **レミの指摘**: 「変えられないことにリソースを割くのは、穴の開いたバケツに水を注ぐようなものよ」

### ページ2：アドラーの断絶

- **内容**: 「過去と他人は変えられない。変えられるのは自分と未来だけ」という核心の提示。
- **視覚演出**: 物理的に「過去」と「自分のフィールド」を断絶する光の壁（境界線）。

### ページ3：4Pという土台（錨）

- **内容**: 過去を引きずらないためには、今の自分を支える「4P（居場所・人々・持ち物・現状）」を固めることが必要。
- **解説**: 4Pが安定しているからこそ、過去の亡霊に振り回されずに済む。

### ページ4：成功者の地平線

- **内容**: 成功者は「船の航跡（過去）」を見ず、常に「向かうべき地平線（未来）」を見ている。
- **結び**: 未来を拓くための具体的な一歩（現状の最適化）を促す演出。

## 視覚的仕様

- **Visual Lock**: レミ（銀髪超ロング、赤眼、赤スーツ、黒レースキャミ）、優斗（短髪黒髪、紺スーツ、青ネクタイ）。
- **Negative Prompt**: 白シャツ、手袋、白襟の禁止。
- **Style**: [PREMIUM DIGITAL MANGA]、V15.5 Edge Obliterator適用。

## 検証方法

- キャラクタースタイルが全ページで統一されているか。
- 日本語のトーンがレミ（凛とした、論理的）と優斗（素直、成長中）に合っているか。
- 4Pの概念が正しく説明されているか。
