# 実装計画: 「脱・漫画」レイアウトへの全面刷新

「格言集」および「本編エピソード」において、漫画的なコマ割り（Panel 1, 2...）を一切廃止し、1ページを1枚の完成した象徴的なイラストとして構築する「フルページ・ポスター形式」を定義・適用します。

## 新レイアウト方針: [v15.5 EDGE OBLITERATOR - POSTER STYLE]

- **コマ割りの廃止**: 従来の `[PANEL 1-40% height]` 等の指定を削除し、ページ全体を一つの巨大なイラストとして構成。
- **視覚情報の統合**: 複数の情報を盛り込む場合は、コマで分けるのではなく、多重露光、背景の描き分け、シンボリックな配置によって1枚の絵の中で表現。
- **テキスト配置**:
  - 画像生成プロンプト内では、テキストを画像の中央、上部、下部へ「浮かぶ金文字」や「装飾エリア」として配置するよう指定。
  - セリフは「吹き出し」としてではなく、画面の上下に「王信」や「天の声」のように配置。
