# ESBIと税金の仕組み：4ページ構成の漫画シナリオ作成計画

ESBIクワドラント（従業員、自営業者、ビジネスオーナー、投資家）の概念と、それぞれの税制上の違い（特に会社員と投資家の格差）を解説する4ページの漫画シナリオを作成します。

## 構成案

- **1ページ目：ESBIクワドラントの導入**
  - 優斗が自分の給与明細の「手取り」の少なさに驚く。
  - レミが登場し、ロバート・キヨサキのESBIクワドラントを提示。
  - 世の中には「労働」の側と「資産」の側の2種類があることを示す。

- **2ページ目：左側の住人（E/S）の過酷な税制**
  - E（従業員）とS（自営業者）が直面する累進課税と社会保険料の壁。
  - 日本の源泉徴収（見えない課税）の恐ろしさを視覚化。
  - 「稼げば稼ぐほど、国家への上納金が増える」構造の指摘。

- **3ページ目：右側の住人（B/I）の特権**
  - B（オーナー）とI（投資家）の税金の違い。
  - 分離課税（一律約20%）の圧倒的優位性。
  - 法人を盾にした経費化と、自分への課税をコントロールする術。

- **4ページ目：結論：右側への脱出**
  - 「税金は無知への罰金である」というレミの指摘。
  - 右側に軸足を移すことが、真の資産形成への第1歩であると結論。
  - 次のステップ（投資の実行）への引き。
