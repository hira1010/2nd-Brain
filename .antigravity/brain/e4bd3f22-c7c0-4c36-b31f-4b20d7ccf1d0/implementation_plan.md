# 実装計画: EP04.8 複利と単利 (Compound vs Simple Interest)

## 概要

ユーザーの要望により、複利と単利（あるいは労働収入の足し算と投資の掛け算）の違いを説明する2ページの漫画プロンプトを作成します。
リファレンス画像に基づき、「人生のコスト（掛け算）」と「労働収入（足し算）」のギャップ（絶望のギャップ）と、それを埋める「投資」を描写します。

## 構成案 (2ページ)

### Page A: 足し算の世界と掛け算の世界

- **概念**:
  - 労働収入 = 足し算 (Linear)
  - 人生コスト (物価上昇など) = 掛け算/指数関数 (Exponential)
- **ビジュアル**:
  - レミがホログラム等のグラフを指し示す。
  - 直線的に伸びる「労働収入」と、二次関数的に急上昇する「人生コスト」。
  - 優斗の見上げる絶望的なグラフ。
- **セリフ**:
  - 「労働収入は足し算。でも、人生のコストは掛け算で増えていくの。」

### Page B: 絶望のギャップと投資の橋

- **概念**:
  - その2つの線が開くにつれて生まれる「絶望のギャップ」。
  - そこに架かる唯一の橋が「投資」。
- **ビジュアル**:
  - 地割れのような深い谷（ギャップ）。
  - 向こう岸（人生コスト）へ届かないこちら側（労働収入）。
  - レミが光る橋（投資）を架ける、あるいは手を差し伸べる。
- **セリフ**:
  - 「この『絶望のギャップ』を埋める唯一の橋、それが投資よ。」
