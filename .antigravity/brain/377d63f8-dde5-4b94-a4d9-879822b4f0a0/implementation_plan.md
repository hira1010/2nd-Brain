# ストーリーフォルダ統合計画

## 概要

`01_ストーリー` フォルダ内に散在するエピソードファイルを統合し、全エピソードが一つのフォルダに正しい時系列順で並ぶようにします。

| 場所 | ファイル | 備考 |
| :--- | :--- | :--- |
| `作成済み/` | EP01〜EP15（15ファイル） | EP01-EP04はそのままでOK確認済み |
| ルート直下 | EP04.5, EP06.5, EP08.5, EP10.5, EP12.5, EP15.5 | 追加.5エピソード |

| ルート直下 | `read_file.py` | ユーティリティ |

## 提案する変更

### ステップ1: `作成済み`フォルダから移動

`作成済み/` フォルダ内の **EP01〜EP15**（15ファイル）を `01_ストーリー/` 直下へ移動します。

> [!IMPORTANT]
> EP01〜EP04はユーザー確認済みで**そのまま**移動します。EP05〜EP15も内容変更なしで移動します。

### ステップ2: `作成済み`フォルダの削除

移動完了後、空になった `作成済み/` フォルダを削除します。

### ステップ3: 不要ファイルの整理

- `read_file.py` → 統合作業後は不要になる可能性あり（ユーザーに確認）
