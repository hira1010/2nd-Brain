# 実装計画書: EP13.28 損切と塩漬けの断絶

「塩漬け」がもたらす再起不能のダメージと、「損切」が真の勝利への布石であることを4Pで解説する4ページのマンガスクリプトを作成します。

## ユーザーレビューが必要な項目

- **損切と塩漬けの4P定義**:
  1. **Pepper (目的/価値)**: 資金の回転効率。死んだ資金を「生きた資金」へ変える。
  2. **Peril (リスク構造)**: 「塩漬け」による機会損失。さらに下がる恐怖ではなく、他のチャンスを逃すリスク。
  3. **Paper (ルール/契約)**: 事前に決めた撤退ライン。感情を介さない「出口戦略」。
  4. **Profit (収益/実り)**: 致命傷を避け、生き残ること自体が次の勝利を保証する。

この定義で、「負けない考え方（不敗）」の延長として構成してよろしいでしょうか？
