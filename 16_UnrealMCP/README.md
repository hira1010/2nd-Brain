## 🛠️ AIと連携するための設定手順

> [!NOTE]  
> **事前確認**
> この作業は「Unreal Engine 5.8」で行います。あらかじめプロジェクトを開いておいてください。

### ステップ 1：プラグイン（拡張機能）をオンにする
1. Unreal Engineの画面上部にある **「編集」** メニューをクリックし、**「プラグイン」** を選びます。
2. 出てきた画面の右上にある検索窓に **`Unreal MCP`** と入力します。
3. 検索結果に出てきたプラグインの横にある**チェックボックスにチェック**を入れて、有効にします。

> [!IMPORTANT]  
> **再起動が必要です**
> チェックを入れると、画面の右下に「今すぐ再起動（Restart Now）」というボタンが出ますので、クリックしてUnreal Engineを再起動してください。

### ステップ 2：サーバーの自動起動を設定する
1. Unreal Engineが再起動したら、再び上部の **「編集」** メニューをクリックし、今度は **「エディタの環境設定」** を選びます。
2. 左側のメニューを少し下へスクロールし、**「Model Context Protocol」** という項目を探してクリックします。
3. 右側の設定画面で **「Auto Start Server（サーバーの自動起動）」** にチェックを入れます。

> [!TIP]  
> **設定完了です！** 🎉
> これで設定はすべて完了しました。AIがあなたのUnreal Engineと「お話し」して、作業を自動でお手伝いできるようになりました！
